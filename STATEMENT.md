# SMART SECURE ATM

### 1. Project Title

**Smart Secure ATM – ATM Management System**

### 2. Problem Statement

To develop a Python-based ATM system that securely performs basic banking operations such as withdrawal, deposit, balance checking, and PIN management.

### 3. Objective

To simulate a real-world ATM using Python while implementing authentication, transaction management, and basic security features.

### 4. Features

* PIN authentication
* Account lock after 3 wrong attempts
* Balance inquiry
* Cash withdrawal and deposit
* PIN change
* Daily and single withdrawal limits
* Mini statement and transaction history
* Security status

### 5. Technology Used

**Python**

### 6. Working

The user enters a PIN for authentication. After successful verification, the user can select an operation from the ATM menu. The system checks the required conditions, performs the transaction, updates the balance, and records the transaction.

### 7. Conclusion

The Smart Secure ATM successfully demonstrates basic ATM operations using Python along with authentication and security mechanisms.
